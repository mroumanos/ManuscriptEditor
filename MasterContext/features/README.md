# Features

One document per feature that outgrew a section of
[05-features.md](../05-features.md). The acceptance criteria stay there; the
*design* — why it is shaped this way, what was tried, what it costs — lives
here.

| Document | What it covers |
|---|---|
| [journal-templates.md](journal-templates.md) | Templates and instances, the four parts, what migrates when, the bundled corpus |
| [ai-assist.md](ai-assist.md) | Connectors, context, intents, the prompt log, fast-forward with Assist |

A feature earns a document here when its "why" stops fitting in a bullet:
when the reasoning behind it is the thing a future reader needs most, and
restating the rules without it would invite the same mistakes again.
